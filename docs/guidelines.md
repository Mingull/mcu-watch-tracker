## Guidelines

- Understand existing code before modifying it.
- Follow the established project structure, architecture and conventions.
- Prefer simple, maintainable solutions over unnecessary abstractions.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.
- Explain significant architectural changes before implementing them.
- Verify API and version compatibility before using new functionality.
- Keep shared functionality independent of application-specific implementations where practical.

The developer makes all final technical and architectural decisions.
