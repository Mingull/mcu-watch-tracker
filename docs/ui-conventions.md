# UI Conventions

- Use Tailwind CSS v4 for styling.
- Prefer existing shadcn/ui components for common UI patterns.
- Custom components are allowed when existing components don't meet the requirements.
- Follow the existing design system for spacing, typography, borders and colors.
- Use theme variables instead of hardcoding colors.
- Keep reusable shared components in `src/components`.
- Keep feature-specific components within their respective feature directories.
- Component filenames should use kebab-case and the `.tsx` extension.
- Dont use hardcoded colors; always use theme variables.
