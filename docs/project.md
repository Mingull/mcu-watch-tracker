# Project Overview

## Purpose

A personal MCU watch tracker for tracking viewing progress through the Marvel Cinematic Universe in chronological order.

## Goals

- Maintain a curated chronological MCU timeline.
- Track watched films, specials, and individual series episodes.
- Save playback positions.
- Provide a Continue Watching overview.
- Support searching and filtering timeline entries.
- Persist and import/export watch progress.
- Display artwork using TMDB.

## Technology Stack

| Area             | Technology              |
| ---------------- | ----------------------- |
| Frontend         | React, Vite, TypeScript |
| Styling          | Tailwind CSS v4         |
| UI               | shadcn/ui (Base UI)     |
| Icons            | Lucide React            |
| Data persistence | localStorage            |
| Artwork          | TMDB API                |
| Package manager  | pnpm                    |

## Project Status

Active development. Core watch tracking and TMDB artwork integration are implemented. UI and detail views are being refined.
