# Minecraft Client

This repository contains a custom Minecraft Java client with a standalone Tauri launcher and a modular Fabric-based client.

use pnpm as the package manager

## Repository layout

- `apps/launcher` contains the standalone Tauri and react-based launcher for the Minecraft client.
- `apps/client` contains the modular Fabric-based Minecraft client.
- `packages/ui` contains shared UI components for the react launcher.
- `packages/eslint-config` contains shared ESLint configurations for the Minecraft client and launcher.
- `packages/typescript-config` contains shared Typescript configurations for the Minecraft client and launcher.
